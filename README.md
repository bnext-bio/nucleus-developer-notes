# README

This repository contains early DevNotes from the b.next Core Development Team for [Nucleus Developer Notes](https://devnotes.nucleus.engineering/), one per folder in `dev-notes/`. Pull requests that change a DevNote build a draft preview, and merging them submits the DevNote to the `bnext-devnotes` venue.

The landing site lives in [nucleus-devnotes-landing](https://github.com/bnext-bio/nucleus-devnotes-landing). To learn more about the Nucleus Ecosystem please visit https://bnext.bio/nucleus.

If you have problems, questions, ideas, or suggestions, please contact us at build@bnext.bio.
